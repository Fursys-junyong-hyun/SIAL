# 유상사급 타처보관 확인서 — 사용 매뉴얼

이 프로그램은 거래처별 재고자산확인서를 자동으로 만들어서 메일로 보내는 도구입니다.
처음에 한 번 설정해 두면, 다음부터는 버튼을 5번 누르면 끝납니다.

---

## 준비물

작업을 시작하기 전에 두 가지가 필요합니다.

1. 사업장별 **자재유형별수불집계** 엑셀 파일 (1개 이상) — 아래 0부에서 다운로드 방법 안내
2. 본인 회사 **Gmail 주소** (예: name@fursys.com)

---

# 0부 · 소스 파일 다운로드 (ERP 에서)

확인서를 만들려면 먼저 ERP 에서 사업장별 자재유형별수불집계 파일을 받아야 합니다.
사업장 1곳당 파일 1개씩 받아두면 됩니다.

## 0-1. ERP 메뉴 위치

ERP 시스템에 로그인한 뒤 왼쪽 메뉴에서 다음 순서로 들어갑니다.

```
자재관리 > 자재실적관리 > 자재유형별수불집계
```

화면 상단 탭 이름이 `자재유형별수불집계(MRS0020_M01)` 인지 확인합니다.

## 0-2. 조회 조건 설정

화면 위쪽 조회 조건 영역에서 다음을 지정합니다.

| 항목 | 값 |
|---|---|
| **사업장** | 받으려는 공장 선택 (예: `퍼시스충주1공장`) |
| **해당년월** | 조회할 분기 시작일 ~ 종료일 (예: `2026-04-01` ~ `2026-06-30` 은 2분기) |
| **수불유형** | 화면 좌측 목록에서 **자재매출** 한 줄만 ☑ 체크 |
| **카테고리대/중/소** | 보통 그대로 두기 (전체) |

> 분기별 기준일 예시
> - 1분기: 01-01 ~ 03-31
> - 2분기: 04-01 ~ 06-30
> - 3분기: 07-01 ~ 09-30
> - 4분기: 10-01 ~ 12-31

## 0-3. 조회 후 엑셀로 저장

오른쪽 위 **조회** 버튼(빨간색)을 누릅니다.

데이터가 표시되면 결과를 엑셀 파일로 저장합니다. (ERP 화면의 엑셀 내보내기 기능 사용)

파일명에 사업장 이름이 들어가도록 합니다. 예: `자재유형별수불집계_퍼시스충주1공장.xls`

## 0-4. 여러 사업장이면 반복

다른 사업장 파일도 필요한 만큼 같은 방법으로 받습니다. 파일은 모두 같은 폴더에 모아두면 편합니다.

---

# 1부 · 처음 한 번만 하는 설정 (메일 보내기 준비)

이 1부는 처음 사용할 때 한 번만 하면 됩니다. 다음부터는 안 해도 됩니다.

## 1-1. 프로그램을 켭니다

바탕화면의 **유상사급 타처보관 확인서** 아이콘을 더블 클릭합니다.

## 1-2. "메일 설정" 탭을 엽니다

프로그램 위쪽에 두 개의 탭이 있습니다.

```
[ 업무 ] [ 메일 설정 ]
```

오른쪽 **메일 설정** 을 클릭합니다.

## 1-3. 내 이름을 입력합니다

**사용자 이름** 칸에 본인 이름을 적습니다.

> 예) `홍길동`

이 이름이 보내는 메일 본문 안에 표시됩니다.

## 1-4. Gmail 앱 비밀번호를 새로 만듭니다

화면에서 파란색 글자로 된 **Gmail 앱 비밀번호 발급 페이지 열기** 를 클릭합니다.

인터넷 브라우저(크롬 등)가 자동으로 열립니다.

브라우저에서 다음을 진행합니다.
1. 본인 회사 Google 계정으로 로그인합니다.
2. **앱 이름** 칸에 알아보기 쉬운 이름을 적습니다.
   > 예) `재고확인서메일`
3. **만들기** (또는 **Generate**) 버튼을 누릅니다.
4. 화면에 16자리 비밀번호가 나타납니다.
   > 예) `abcd efgh ijkl mnop`
5. 이 비밀번호를 마우스로 드래그해서 복사합니다. (`Ctrl + C`)

⚠️ **중요**: 이 비밀번호는 화면이 닫히면 다시 볼 수 없습니다. 닫기 전에 반드시 복사해서 다음 단계로 진행하세요.

## 1-5. 프로그램에 입력합니다

프로그램으로 돌아옵니다.

- **Gmail 주소** 칸: 본인 회사 Gmail 주소를 적습니다.
  > 예) `hong@fursys.com`
- **앱 비밀번호** 칸: 방금 복사한 16자리를 붙여넣기 합니다. (`Ctrl + V`)
  - 공백이 있어도 괜찮습니다. 저장할 때 자동으로 정리됩니다.

## 1-6. 연결이 되는지 확인합니다

**Gmail 연결 테스트** 버튼을 누릅니다.

- 화면에 ✅ **Gmail 로그인 성공** 이 나오면 잘 된 것입니다.
- 만약 ❌ 오류가 나오면 1-4부터 다시 시도하세요.

## 1-7. 설정을 저장합니다

화면 오른쪽 아래 **설정 저장** 버튼을 누릅니다.

`메일 설정과 업체 이메일을 저장했습니다.` 라는 메시지가 나오면 끝입니다.

이제 1부는 모두 끝났습니다. 다음부터는 이 화면을 다시 열 필요가 없습니다.

# 2부 · 매번 하는 작업 (확인서 만들고 메일 보내기)

여기는 매번 작업할 때마다 하는 단계입니다. 화면 위쪽에 있는 순서를 그대로 따라가면 됩니다.

```
① 소스 파일 추가 → ② 거래처 불러오기 → ③ 거래처 선택 → ④ 산출 실행 → ⑤ 메일 발송
```

## ① 엑셀 파일 추가하기

**업무** 탭이 선택되어 있는지 확인합니다.

화면 왼쪽 위 **소스 파일** 영역에서 **파일 추가** 버튼을 누릅니다.

파일 선택 창이 열리면, 받아온 **자재유형별수불집계** 엑셀 파일을 고릅니다.
- 한 번에 여러 개를 골라도 됩니다. (`Ctrl` 키를 누르면서 클릭)
- 잘못 추가한 파일은 그 줄을 클릭한 뒤 **선택 제거** 버튼으로 뺄 수 있습니다.

추가된 파일의 "사업장" 칸에 표시된 이름이 다르다면, 그 칸을 더블 클릭해서 직접 고칠 수 있습니다.

## ② 거래처 불러오기

소스 파일 영역의 오른쪽 아래에 있는 **② 거래처 불러오기** 버튼을 누릅니다.

잠깐 기다리면 화면 오른쪽에 거래처 목록이 나타납니다.

`거래처 N개를 불러왔습니다.` 라는 메시지가 나오면 다음 단계로 갑니다.

## ③ 보낼 거래처 고르기

화면 오른쪽 **거래처 선택** 영역에서, 보내려는 업체 앞의 네모 칸(체크박스)을 클릭해서 ☑로 만듭니다.

찾는 방법:
- 검색 칸에 업체 이름의 일부를 입력하면 해당 업체만 보입니다.
- 한 번에 다 선택하려면 **현재 목록 전체 선택** 을 누릅니다.

선택한 업체 수는 화면 위쪽 요약줄에 표시됩니다.

## ③.5 저장 폴더 정하기

화면 왼쪽 아래 **출력 옵션** 영역에서:
- **기준일**: 확인서 기준 날짜 (보통 그대로 두면 됩니다 — 전월 말일이 자동 입력됨)
- **저장 폴더**: **폴더 선택** 버튼을 눌러 산출물을 저장할 폴더를 고릅니다.
  - 예: 바탕화면에 `재고확인서_2026년1분기` 같은 새 폴더를 만들어 사용합니다.

## ④ 산출 실행 (Excel/PDF 만들기)

화면 맨 아래 오른쪽 끝의 **④ 산출 실행** 버튼을 누릅니다.

`총 N개 업체의 Excel/PDF를 생성했습니다.` 메시지가 나오면 성공입니다.

정한 저장 폴더 안에 들어가 보면:
- 업체 이름별로 폴더가 만들어져 있습니다.
- 각 폴더 안에 엑셀 파일과 PDF 파일이 각각 1개씩 있습니다.

확인할 일이 있으면 폴더를 열어 미리 봅니다.

## ⑤ 메일 발송

**④ 산출 실행** 버튼 오른쪽의 **⑤ 메일 발송** 버튼을 누릅니다.

새 창이 열립니다. 이 창에서 메일 내용을 마지막으로 확인하고 발송합니다.

### 화면 보는 법

화면은 위에서 아래로 세 부분입니다.

1. **1단계 · 발송 설정**
   - 발송 방식: 보통 `Gmail (앱 비밀번호 / SMTP)` 그대로 둡니다.
   - 회신 요청일: 거래처에게 언제까지 답을 달라고 할지. 자동으로 다음 주 금요일이 들어갑니다. 다른 날짜로 바꿔도 됩니다.
   - 미리보기 업체: 가운데 미리보기에 어느 업체를 기준으로 보여줄지 고릅니다.

2. **2단계 · 메일 내용**
   - 왼쪽: 제목과 본문의 **편집 가능한 템플릿**. 모든 업체에 공통으로 적용됩니다.
   - 오른쪽: 위에서 고른 미리보기 업체 기준으로 **실제 발송될 모양**. 편집 못함, 확인만.
   - 본문에 `{vendor_name}` 같은 변수를 쓰면 거래처마다 자동으로 이름이 바뀌어 들어갑니다.

3. **3단계 · 발송 대상**
   - 보낼 업체와 이메일 주소 목록입니다.
   - **상태** 칸 표시
     - ✅ 발송 가능 — 이상 없음
     - ✉️ 이메일 미입력 — 그 거래처 이메일을 입력해야 합니다
     - ⚠️ 이메일 형식 오류 — 주소를 잘못 적었거나 `@`가 빠졌습니다
     - 📎 첨부파일 없음 — 산출 실행이 안 됐습니다. 창을 닫고 ④ 산출 실행을 다시 합니다.

### 이메일 주소가 빈 거래처가 있다면

표에서 그 줄의 **이메일** 칸을 더블 클릭하고 주소를 입력합니다.
한 번 입력해 두면 다음번에는 자동으로 채워집니다.

### 보내기

오른쪽 아래 **발송** 버튼을 누릅니다.

`이대로 발송하시겠습니까?` 가 나오면 **예** 를 누릅니다.

발송이 끝나면 결과 창이 뜹니다.
- ✅ 성공 N건 — 잘 보내진 메일 수
- ❌ 실패 N건 — 실패한 메일과 이유
- ⏭️ 제외 N건 — 이메일이 없거나 잘못된 거래처

# 3부 · 문제가 생겼을 때

## "거래처가 없어요" / 거래처 목록이 비어 있어요

- ① 소스 파일을 먼저 추가했는지 확인합니다.
- 추가한 뒤 **② 거래처 불러오기** 버튼을 눌렀는지 확인합니다.

## **⑤ 메일 발송** 버튼이 회색이라 안 눌려요

- 먼저 **④ 산출 실행** 을 눌러서 엑셀/PDF를 만들어야 메일을 보낼 수 있습니다.
- 버튼 위에 마우스를 올리면 무엇이 빠졌는지 알려주는 안내가 나옵니다.

## 일부 거래처가 "이메일 미입력" 으로 제외돼요

- 메일 발송 화면의 표에서 그 거래처 줄의 **이메일** 칸을 더블 클릭해서 직접 적어줍니다.
- 한 번 적어 두면 다음 작업부터는 자동으로 채워집니다.

## "Gmail 인증 실패" 라고 나와요

- 1부의 1-4 단계부터 다시 진행해서 앱 비밀번호를 새로 만들어 주세요.
- 새 비밀번호를 입력하고 **Gmail 연결 테스트** 로 확인합니다.

## 정말로 안 보내져요 (인터넷 문제 등)

메일 발송 창의 **발송 방식** 을 **EML 초안 파일로 저장** 으로 바꿔서 발송합니다.
- 저장 폴더 안에 `_메일초안_EML` 폴더가 생기고, 거래처별 `.eml` 파일이 만들어집니다.
- 그 파일을 더블 클릭하면 Outlook 같은 메일 프로그램에서 첨부까지 다 들어간 채로 열립니다.
- 그 상태에서 **보내기** 만 누르면 됩니다.

## 잘못 만들어서 다시 만들고 싶어요

- 같은 저장 폴더에서 ④ 산출 실행을 다시 누르면 됩니다.
- `같은 이름의 파일 N건이 이미 있습니다.` 가 나오면 **예** 를 눌러 덮어쓰기 합니다.

# 한눈에 보는 화면 구조

```
┌─────────────────────────────────────────────────────────────────┐
│  [ 업무 ]  [ 메일 설정 ]    ← 위쪽 큰 탭                          │
├─────────────────────────────────────────────────────────────────┤
│  진행 순서: ① 파일 추가 → ② 불러오기 → ③ 선택 → ④ 산출 → ⑤ 메일 │
├─────────────────────────────────────────────────────────────────┤
│  요약: 소스 파일 N건 · 거래처 N개 · 선택 N개 · 산출물 N건         │
├──────────────────────────────────┬──────────────────────────────┤
│ ① 소스 파일                       │ ③ 거래처 선택                 │
│  [파일 추가] [선택 제거]          │  [검색 칸]                    │
│  파일 목록 표                     │  ☐ 거래처1                    │
│                                   │  ☐ 거래처2                    │
│  [② 거래처 불러오기]              │  ...                          │
│                                   │                               │
│ 출력 옵션                         │                               │
│  기준일: [____]                   │                               │
│  저장 폴더: [____] [폴더 선택]    │                               │
├─────────────────────────────────────────────────────────────────┤
│  선택 업체 미리보기                                              │

└─────────────────────────────────────────────────────────────────┘
```

# 도움이 필요할 때

이 매뉴얼로 해결이 안 되면 IT 담당자에게 다음 정보를 알려주세요.

- 어느 단계에서 문제가 생겼는지 (예: "③ 거래처 선택 후 ④ 산출 실행에서 막힘")
- 화면에 나온 오류 메시지 전체
- 처음 시도한 거래처 수와 실제 성공/실패 수
