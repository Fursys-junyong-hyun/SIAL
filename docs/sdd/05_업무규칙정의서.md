# 05. 업무 규칙 정의서

## 업무 규칙

| ID | 규칙 |
|---|---|
| BR-001 | 소스 파일은 1건 이상 등록되어야 한다. |
| BR-002 | 소스 파일 읽기 대상 시트는 `Sheet1`이다. |
| BR-003 | 컬럼 위치가 달라도 컬럼명 기준으로 값을 식별한다. |
| BR-004 | 거래처 선택 기준은 `거래처명` 단일 컬럼이다. |
| BR-005 | 여러 거래처를 동시에 선택할 수 있다. |
| BR-006 | 동일 `자재코드 + 색상` 중복 건은 첫 번째 행만 사용한다. |
| BR-007 | 여러 사업장에 동일 키가 존재해도 합산하지 않고 별도 행으로 유지한다. |
| BR-008 | 출력 정렬은 사업장, 자재코드, 색상의 오름차순이다. |
| BR-009 | `자재명`이 없으면 `비고`는 빈칸으로 출력한다. |
| BR-010 | `보관 수량`은 항상 공란으로 남긴다. |
| BR-011 | 본문 데이터는 4행부터 출력한다. |
| BR-012 | 페이지가 넘어가면 헤더는 반복한다. |
| BR-013 | 꼬리표는 마지막 페이지에만 출력한다. |
| BR-014 | 양식 기준일자는 실행일을 사용한다. |
| BR-015 | 동일 산출 파일이 존재하면 사용자 확인 전 덮어쓰지 않는다. |
| BR-016 | 미리보기는 검토 전용이며 수정 기능을 제공하지 않는다. |
| BR-017 | 업체별 폴더를 별도로 생성한다. |

## 페이지 분할 규칙
- 헤더는 1~3행 블록이다.
- 꼬리표는 31~33행 블록이다.
- 마지막 페이지를 제외한 페이지는 헤더와 본문만 포함한다.
- 마지막 페이지는 헤더, 본문, 꼬리표를 포함한다.
- 페이지당 본문 최대 행 수는 양식 실제 구조 확인 후 확정 필요이다.

## 파일명 및 저장 규칙
- 파일명 형식은 `거래처명_재고자산확인서_YYMMDD`이다.
- 날짜는 실행일 기준 2자리 연도, 2자리 월, 2자리 일 형식이다.
- 저장 경로는 사용자가 선택한 루트 폴더 하위에 거래처별 폴더를 만든다.

## 미정 또는 사용자 확인 필요
- 페이지당 본문 허용 행 수 계산 규칙
- 사업장명 자동 추출 시 파일명 파싱 규칙의 세부 조건
