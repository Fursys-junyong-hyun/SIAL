# 04. 데이터 정의서

## 입력 파일

| 항목 | 내용 |
|---|---|
| 파일 유형 | Excel |
| 파일 예시 | `자재유형별수불집계_FC1.xls`, `자재유형별수불집계_FC2.xls` |
| 시트명 | `Sheet1` |
| 시트 수 | 일반적으로 1개 |

## 입력 컬럼 정의

| 컬럼명 | 필수 | 설명 | 비고 |
|---|---|---|---|
| 거래처명 | 예 | 업체 선택 기준 컬럼 | 드롭다운 목록 구성에 사용 |
| 자재코드 | 예 | 출력 자재코드 | 키 컬럼 |
| 색상 | 예 | 출력 색상코드 | 키 컬럼, 원문 그대로 출력 |
| 자재명 | 아니오 | 출력 비고 | 값 없으면 빈칸 |

## 데이터 식별 및 변환 규칙

| 항목 | 규칙 |
|---|---|
| 키값 | `자재코드 + 색상` |
| 중복 처리 | 동일 키 중 첫 번째 행 사용 |
| 정렬 | 사업장 오름차순 > 자재코드 오름차순 > 색상 오름차순 |
| 누락값 처리 | 빈칸 출력 |
| 사업장 표시 | 사용자가 확정한 사업장명 사용 |

## 출력 파일

| 항목 | 내용 |
|---|---|
| 산출 형식 | `.xlsx`, `.pdf` |
| 파일명 규칙 | `거래처명_재고자산확인서_YYMMDD` |
| 날짜 기준 | 실행일 |
| 저장 구조 | `저장폴더\거래처명\거래처명_재고자산확인서_YYMMDD.*` |

## 양식 매핑 정의

| 출력 항목 | 소스/값 | 규칙 |
|---|---|---|
| 사업장 | 사업장 입력값 | 파일명 자동 추출 후 사용자 수정 가능 |
| 업체명 | 거래처명 | 선택한 거래처명 |
| 자재코드 | 자재코드 | 원문 사용 |
| 색상코드 | 색상 | 원문 사용 |
| 비고 | 자재명 | 빈값 허용 |
| 보관 수량 | 공란 | 프로그램 미기입 |
| 기준일자 문구 | 실행일 | `B2` 셀에 `재고자산확인서 ('YY년 MM월 DD일 기준)` 형식 적용 |

## 미정 또는 사용자 확인 필요
- 양식 내 각 출력 항목의 정확한 셀/열 좌표
- 다중 페이지 생성 시 페이지별 시작 행과 반복 블록의 정확한 레이아웃 정의
