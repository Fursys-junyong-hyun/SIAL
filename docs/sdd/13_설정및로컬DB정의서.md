# 13. 설정 및 로컬 DB 정의서

## 목적
- 사용자별 메일 설정과 거래처 이메일 주소를 로컬 환경에 저장한다.

## 저장 위치

| 항목 | 저장 방식 |
|---|---|
| 일반 설정 | SQLite |
| 거래처 이메일 | SQLite |
| Gmail SMTP 비밀번호 | Windows 자격 증명 저장소 |
| 최근 사용 폴더 | QSettings |

## SQLite 대상
- 사용자 이름
- 기본 발송 방식
- Gmail SMTP 호스트
- Gmail SMTP 포트
- Gmail SMTP 사용자 계정
- TLS 사용 여부
- 메일 제목 템플릿
- 메일 본문 템플릿
- 거래처명-이메일 매핑

## 테이블 정의

### app_settings

| 컬럼 | 타입 | 설명 |
|---|---|---|
| key | TEXT PK | 설정 키 |
| value | TEXT | 설정 값 |

### vendor_emails

| 컬럼 | 타입 | 설명 |
|---|---|---|
| vendor_name | TEXT PK | 거래처명 |
| email | TEXT | 거래처 이메일 |

## 보안 정책
- SMTP 비밀번호는 SQLite에 저장하지 않는다.
- SMTP 비밀번호는 Windows 자격 증명 저장소에 저장한다.
- 업체 이메일과 일반 설정은 사용자 PC 로컬 환경에만 저장한다.

## 동기화 규칙
- 현재 불러온 거래처 목록을 설정 탭의 이메일 매핑 표로 가져올 수 있어야 한다.
- 기존에 저장된 업체는 이메일 값을 유지하고, 신규 업체만 빈 이메일로 추가한다.
