# 12. 메일 기능 정의서

## 목적
- 생성된 거래처별 재고자산확인서 Excel/PDF를 프로그램 내부에서 바로 메일 발송할 수 있도록 한다.
- 현재는 Outlook과 Gmail(SMTP)을 함께 지원하고, 사용자 설정에 따라 기본 발송 방식을 선택한다.

## 발송 방식

| 구분 | 내용 |
|---|---|
| Outlook | 즉시 발송 지원 |
| Gmail | SMTP 발송 지원 |
| 기본 발송 방식 | 사용자별 저장 후 필요 시 변경 |

## 발송 대상 규칙

| 항목 | 규칙 |
|---|---|
| 첨부파일 | 거래처별 Excel + PDF 2개를 항상 첨부 |
| 이메일 주소 없음 | 해당 업체는 발송 대상에서 제외하고 경고 팝업 표시 |
| 발송 전 확인 | 발송 방식, 대상 업체 수, 제외 업체 수를 확인 후 진행 |
| 발송 결과 | 이력 저장 없이 결과 팝업으로만 표시 |

## 메일 제목/본문 규칙

### 제목 기본 템플릿
- `[{vendor_name}] 재고자산확인서 송부 (기준일: {report_date_kr})`

### 본문 기본 템플릿
- 사용자 수정 가능
- 기본 치환 변수 사용

### 치환 변수

| 변수 | 설명 |
|---|---|
| `{vendor_name}` | 거래처명 |
| `{sender_name}` | 설정 탭에 저장한 사용자 이름 |
| `{quarter}` | 기준일 기준 분기 |
| `{period_year}` | 기준일 연도 |
| `{period_start_month}` | 분기 시작 월 |
| `{period_end_month}` | 분기 종료 월 |
| `{report_date_kr}` | `YY년 MM월 DD일` 형식 기준일 |
| `{reply_due_kr}` | `MM/DD(요일)` 형식 회신 요청일 |

## 화면 요구사항
- 설정 탭에서 기본 발송 방식, 사용자 이름, SMTP 정보를 관리한다.
- 설정 탭에서 거래처별 이메일 주소를 관리한다.
- 메일 발송 대화상자에서 제목 템플릿, 본문 템플릿, 회신 요청일, 발송 방식을 확인 및 수정한다.
- 발송 대화상자에서 발송 대상/제외 대상을 구분해서 보여준다.

## 예외 처리
- 첨부파일이 없으면 해당 업체 발송을 제외하고 오류 목록에 표시한다.
- Gmail SMTP 인증 실패 시 즉시 중단하고 오류 팝업을 표시한다.
- Outlook 클라이언트를 사용할 수 없으면 즉시 중단하고 오류 팝업을 표시한다.
