# 12. 메일 기능 정의서

## 목적
- 생성된 거래처별 재고자산확인서 Excel/PDF를 프로그램 내부에서 바로 발송하거나 메일 초안으로 저장할 수 있도록 한다.
- 회사 전 계정이 Gmail로 통합됨에 따라 **Gmail 앱 비밀번호(SMTP) 발송이 기본**이며, 환경에 따라 OAuth / Outlook / EML 초안 저장도 선택할 수 있다.

## 발송 방식

| 구분 | 인증 | 설명 |
|---|---|---|
| **Gmail (앱 비밀번호)** — 권장 | SMTP 로그인 | 2단계 인증 + 16자리 앱 비밀번호 사용. 발급 페이지(`https://myaccount.google.com/apppasswords`)에서 비밀번호를 만든 뒤 메일 설정 탭에 입력. |
| Gmail (OAuth) — 대체 | Google 로그인 | 앱 비밀번호가 차단된 미래 환경 대비. Google Cloud Console 에 등록한 OAuth 클라이언트로 사용자 동의를 받고 XOAUTH2 로 SMTP 발송. |
| Outlook (PC 클라이언트) | PC 기본 Outlook | PC 의 Outlook 이 Gmail 계정에 연결돼 있을 때 사용. |
| EML 초안 파일 저장 | 인증 불필요 | 발송하지 않고 `.eml` 파일로 저장. 사용자가 Outlook 등에서 더블클릭해 첨부 포함 메일을 열고 직접 발송. |

### Gmail 앱 비밀번호 (권장)
- 일반 Google 비밀번호는 SMTP 로그인 시 거부된다. 반드시 **앱 비밀번호**를 사용해야 한다.
- 발급 절차
  1. Google 계정에서 2단계 인증 활성화
  2. `https://myaccount.google.com/apppasswords` 접속 (메일 설정 탭의 "Gmail 앱 비밀번호 발급 페이지 열기" 버튼으로 바로 이동 가능)
  3. 앱 이름을 입력하고 비밀번호 생성 → 16자리 문자열을 그대로 복사
- 입력값에 공백이 있어도 저장 시 자동으로 제거된다(`xxxx xxxx xxxx xxxx` 형식 그대로 붙여넣기 가능).
- "Gmail 연결 테스트" 버튼으로 실제 발송 전에 로그인 가능 여부를 검증할 수 있다.

### Gmail OAuth (대체 옵션)
- 회사 OU 정책이 앱 비밀번호를 차단했을 때를 대비한 보조 경로.
- 사용하려면 IT/관리자가 Google Cloud Console 에서 "데스크톱 앱" OAuth 클라이언트를 1회 등록해야 한다.
- 메일 설정 탭의 "Gmail Google 로그인 (대체 옵션)" 박스를 펼쳐 Client ID/Secret 을 입력한 뒤 "Google 로그인"을 누르면 브라우저로 동의 화면이 열린다.
- 일반 사용 환경에서는 앱 비밀번호 방식이면 충분하므로 OAuth 박스는 기본적으로 접혀 있다.

### EML 초안 파일 저장
- 발송 다이얼로그에서 "EML 초안 파일로 저장"을 선택하면, 산출물 저장 폴더 하위 `_메일초안_EML/` 폴더에 거래처별 `.eml` 파일을 만든다.
- 각 `.eml` 파일은 첨부(Excel + PDF) 까지 모두 포함된 RFC 5322 메시지이므로, Outlook/Thunderbird 등에서 더블클릭하면 "보내기"만 누르면 되는 상태로 열린다.
- 발송 권한이 전혀 없는 비상 상황에서도 동작.

## 자격증명 저장 위치

| 항목 | 저장소 |
|---|---|
| Gmail 앱 비밀번호 | Windows Credential Manager (`outsourced_inventory_confirmation_gmail_smtp`) |
| OAuth Client Secret | Windows Credential Manager (`outsourced_inventory_confirmation_gmail_oauth_client_secret`) |
| OAuth Refresh Token | Windows Credential Manager (`outsourced_inventory_confirmation_gmail_oauth_refresh`) |
| OAuth Client ID / 계정 이메일 | 앱 로컬 SQLite (`app.db`) |

## 발송 대상 규칙

| 항목 | 규칙 |
|---|---|
| 첨부파일 | 거래처별 Excel + PDF 2개를 항상 첨부 |
| 이메일 주소 없음 | 발송 대상에서 제외하고 결과 화면에 사유 표시 |
| 이메일 형식 오류 | 발송 대상에서 제외하고 결과 화면에 사유 표시 |
| 첨부파일 없음 | 발송 대상에서 제외하고 "산출 실행 필요"로 안내 |
| 발송 전 확인 | 발송 방식, 대상 업체 수, 제외 업체 수를 확인 후 진행 |
| 발송 결과 | 이력 저장 없이 성공/실패/제외 합산 결과를 팝업으로 표시. EML 모드에서는 저장 폴더 열기 버튼 제공. |

## 메일 제목/본문 규칙

### 제목 기본 템플릿
- `[{vendor_name}] 재고자산확인서 송부 (기준일: {report_date_kr})`

### 본문 기본 템플릿
- 사용자 수정 가능
- 발송 대화상자에서 **선택 업체 기준 미리보기**를 실시간으로 확인할 수 있다.
- 발송 시 거래처별로 템플릿을 다시 렌더링하므로, 본문에 `{vendor_name}` 등을 사용해도 거래처마다 다른 값으로 치환된다.

### 치환 변수

| 변수 | 설명 |
|---|---|
| `{vendor_name}` | 거래처명 |
| `{sender_name}` | 메일 설정 탭에 저장한 사용자 이름 |
| `{quarter}` | 기준일 기준 분기 |
| `{period_year}` | 기준일 연도 |
| `{period_start_month}` | 분기 시작 월 |
| `{period_end_month}` | 분기 종료 월 |
| `{report_date_kr}` | `YY년 MM월 DD일` 형식 기준일 |
| `{reply_due_kr}` | `MM/DD(요일)` 형식 회신 요청일 |

## 화면 요구사항
- 메일 설정 탭은 다음 순서의 박스로 구성한다.
  1. 발신자 정보 / 기본 발송 방식
  2. Gmail 앱 비밀번호 (권장) — 펼쳐진 상태
  3. Gmail Google 로그인 (대체 옵션) — 접힌 상태, 필요 시 펼침
  4. 메일 템플릿 기본값
  5. 업체 이메일 관리
- 메일 발송 대화상자에서 발송 방식 콤보는 4개 옵션 순서대로 표시한다(SMTP / OAuth / Outlook / EML).
- 회신 요청일 기본값은 **다음 주 금요일**로 자동 채워진다.
- 발송 대상 표의 이메일 칸은 직접 편집할 수 있으며, 편집 시 즉시 상태가 갱신되고 자동 저장된다.

## 메인 화면의 단계 안내
- 화면 상단에 진행 순서(`① 소스 파일 추가 → ② 거래처 불러오기 → ③ 거래처 선택 → ④ 산출 실행 → ⑤ 메일 발송`)를 항상 표시한다.
- 각 단계 버튼은 선행 조건이 충족되어야만 활성화된다.

## 예외 처리
- 첨부파일이 없으면 해당 업체 발송을 제외하고 결과 화면에 "산출 실행 필요" 사유를 표시한다.
- 이메일 형식이 잘못된 경우 발송 대상에서 제외하고 사유를 표시한다.
- Gmail 앱 비밀번호 인증 실패 시 2단계 인증/앱 비밀번호 사용 여부를 안내하는 체크리스트를 표시한다.
- OAuth refresh token 이 만료/취소된 경우 즉시 중단하고, 메일 설정 탭에서 재로그인하도록 안내한다.
- Outlook 클라이언트를 사용할 수 없으면 즉시 중단하고 오류 팝업을 표시한다.
- 자격증명이 모두 비어있는 상태에서 메일 발송을 시도하면 메일 설정 탭으로 안내한다.
- EML 모드에서는 인증 오류가 발생하지 않으며, 저장 디스크 권한 오류만 실패 사유로 표시한다.
