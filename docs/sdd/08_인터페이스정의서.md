# 08. 인터페이스 정의서

## 파일 인터페이스

### 입력 인터페이스

| 항목 | 내용 |
|---|---|
| 입력 매체 | 로컬 파일 선택 |
| 입력 형식 | Excel (`.xls`, `.xlsx`, 필요 시 `.xlsm` 읽기 여부 별도 구현 판단) |
| 입력 파일 수 | 1건 이상 |
| 시트 | `Sheet1` |

### 출력 인터페이스

| 항목 | 내용 |
|---|---|
| 출력 형식 | Excel, PDF |
| 저장 위치 | 사용자가 선택한 폴더 하위 거래처별 폴더 |
| 파일명 | `거래처명_재고자산확인서_YYMMDD` |

## 내부 모듈 인터페이스

| 인터페이스 | 입력 | 출력 |
|---|---|---|
| 파일 분석 | 파일 경로 목록, 사업장명 목록 | 거래처 목록, 원본 데이터 |
| 미리보기 생성 | 선택 거래처, 원본 데이터, 기준일 | 업체별 출력 테이블 |
| Excel 생성 | 업체별 출력 데이터, 양식 파일, 기준일 | `.xlsx` 파일 |
| PDF 생성 | `.xlsx` 또는 렌더링 데이터 | `.pdf` 파일 |
| 설정 저장 | 최근 사용 폴더 | 저장 성공/실패 |

## 외부 시스템 인터페이스
- 현재 확정된 외부 시스템 연동 없음
- DB 연동 없음
- ERP 직접 연동 없음

## 경로 규칙
- 양식 파일은 배포 패키지 내부 리소스로 포함하는 방향이 유력하나 확정 전이다.
- 최근 사용 폴더 저장 위치는 사용자 프로필 하위 설정 파일 방식이 유력하나 확정 전이다.

## 미정 또는 사용자 확인 필요
- `.xlsm` 입력 지원 범위
- 템플릿 파일 배포 위치
- 설정 파일 저장 경로
