# 02. 업무 프로세스 흐름도

## 시작 조건
- 사용자가 프로그램을 실행한다.
- 확인서 생성에 사용할 사업장별 `자재유형별수불집계` 파일을 보유하고 있다.

## 입력
- 사업장별 소스 Excel 파일 1건 이상
- 사업장명
  - 파일명에서 기본값 자동 추출
  - 사용자가 수정 가능
- 거래처 선택
  - `거래처명` 기준
  - 검색 가능한 체크박스 다중 선택
- 저장 대상 폴더

## 처리 단계
1. 사용자가 소스 파일을 1건 이상 등록한다.
2. 시스템이 각 파일에서 사업장 기본값을 추출해 표시한다.
3. 시스템이 각 파일의 `Sheet1`에서 거래처명 목록을 수집한다.
4. 사용자가 거래처를 검색하고 다중 선택한다.
5. 시스템이 선택 거래처별 데이터를 읽고 `자재코드 + 색상` 기준으로 중복을 제거한다.
6. 시스템이 사업장 오름차순, 자재코드 오름차순, 색상 오름차순으로 정렬한다.
7. 시스템이 양식 기반 미리보기를 생성한다.
8. 사용자가 미리보기를 검토하고 생성 실행을 확정한다.
9. 시스템이 업체별 폴더를 생성하고 Excel 파일을 만든다.
10. 시스템이 동일 레이아웃 기준의 PDF 파일을 생성한다.

## 예외 흐름
- 소스 파일을 읽을 수 없으면 생성 전 중단하고 오류를 표시한다.
- 기존 산출 파일이 있으면 덮어쓰기 여부를 확인한다.
- 일부 값이 비어 있으면 빈칸으로 출력하고 계속 진행한다.

## 종료 조건
- 선택한 각 거래처별 폴더에 Excel/PDF가 생성된다.
- 또는 치명적 오류 발생 시 생성이 중단되고 사용자에게 안내된다.
