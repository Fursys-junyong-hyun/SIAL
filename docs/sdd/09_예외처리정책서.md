# 09. 예외 처리 정책서

## 예외 유형 및 처리 기준

| ID | 예외 유형 | 메시지 방향 | 처리 기준 |
|---|---|---|---|
| EX-001 | 소스 파일 미선택 | 소스 파일을 1개 이상 선택하라는 안내 | 중단 |
| EX-002 | 저장 폴더 미선택 | 저장 위치를 선택하라는 안내 | 중단 |
| EX-003 | 거래처 미선택 | 거래처를 1개 이상 선택하라는 안내 | 중단 |
| EX-004 | 파일 읽기 실패 | 파일 형식 또는 손상 여부 확인 안내 | 중단 |
| EX-005 | `Sheet1` 없음 | 시트명을 확인하라는 안내 | 중단 |
| EX-006 | 필수 컬럼 누락 | 누락 컬럼명을 표시 | 중단 |
| EX-007 | 일부 값 누락 | 누락 항목은 빈칸으로 출력된다는 안내 | 계속 |
| EX-008 | 동일 산출 파일 존재 | 덮어쓰기 여부 확인 | 사용자 결정 필요 |
| EX-009 | PDF 생성 실패 | PDF 생성 실패와 재시도 필요 안내 | 중단 |
| EX-010 | Excel 생성 실패 | 산출 파일 생성 실패 안내 | 중단 |
| EX-011 | 권한 부족 또는 경로 접근 실패 | 저장 경로 권한 확인 안내 | 중단 |

## 메시지 정책
- 오류 메시지는 어떤 파일, 어떤 거래처, 어떤 컬럼에서 문제가 발생했는지 가능한 범위에서 구체적으로 표시한다.
- 다중 업체 일괄 생성 중 실패가 발생하면 실패 대상과 성공 대상을 구분해 보여줄 필요가 있다.

## 중단/계속 원칙
- 입력 구조를 해석할 수 없는 오류는 중단한다.
- 값 일부 누락은 빈칸 출력 후 계속한다.
- 덮어쓰기 여부는 사용자 확인 후 진행한다.

## 로그 정책
- 생성 이력 로그는 필수 요구사항이 아니다.
- 디버깅용 내부 오류 기록 여부는 구현 시 판단 필요이다.

## 미정 또는 사용자 확인 필요
- 일괄 생성 중 일부 업체 실패 시 전체 중단 여부 또는 실패 건만 제외하고 계속할지
