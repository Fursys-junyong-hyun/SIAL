# 10. 테스트 케이스

| ID | 관련 요구사항 | 전제 조건 | 입력 | 예상 결과 |
|---|---|---|---|---|
| TC-001 | FR-001, FR-002, FR-003 | 프로그램 실행 | 소스 파일 1건 선택 | 파일이 목록에 추가되고 사업장 기본값이 자동 표시된다. |
| TC-002 | FR-004, FR-005, FR-006 | 유효한 소스 파일 등록 | 거래처 검색어 입력, 다중 체크 | 검색 결과가 필터링되고 여러 거래처 선택이 가능하다. |
| TC-003 | FR-007, FR-008 | 동일 거래처에 중복 키 존재 | 거래처 선택 | 동일 `자재코드 + 색상`은 첫 번째 행만 반영된다. |
| TC-004 | FR-012 | 동일 키가 여러 사업장에 존재 | 다중 사업장 파일 등록 | 합산되지 않고 사업장별 별도 행으로 출력된다. |
| TC-005 | FR-013, FR-014 | 거래처 선택 완료 | 미리보기 생성 | 출력 예정 데이터가 표시되고 편집은 불가능하다. |
| TC-006 | FR-015, FR-016 | 저장 폴더 선택 완료 | 산출 실행 | 거래처별 폴더와 규칙에 맞는 파일명이 생성된다. |
| TC-007 | FR-017 | 시스템 날짜 확인 가능 | 산출 실행 | `B2` 셀에 `재고자산확인서 ('YY년 MM월 DD일 기준)` 형식 문구가 반영된다. |
| TC-008 | FR-018, FR-019 | 본문이 1페이지를 초과하는 데이터 준비 | 산출 실행 | 다음 페이지가 자동 생성되고 헤더는 반복되며 꼬리표는 마지막 페이지에만 출력된다. |
| TC-009 | FR-020 | 동일 파일 존재 | 산출 실행 | 덮어쓰기 확인 창이 표시된다. |
| TC-010 | FR-021 | 최근 사용 폴더 저장 기능 구현 완료 | 프로그램 재실행 | 최근 사용 폴더가 복원된다. |
| TC-011 | NFR-001, NFR-002 | Office 미설치 Windows 환경 | 산출 실행 | Excel/PDF가 정상 생성된다. |
| TC-012 | NFR-003 | 샘플 양식 준비 | PDF 생성 | PDF 레이아웃이 양식과 거의 동일하다. |
| TC-013 | NFR-005 | 컬럼 위치가 다른 소스 파일 준비 | 산출 실행 | 컬럼명 기준으로 정상 매핑된다. |
| TC-014 | EX-006 | 필수 컬럼 누락 파일 준비 | 산출 실행 | 누락 컬럼 안내 후 생성이 중단된다. |
| TC-015 | EX-007 | `자재명` 누락 행 포함 | 산출 실행 | `비고`가 빈칸으로 출력되고 생성은 계속된다. |
