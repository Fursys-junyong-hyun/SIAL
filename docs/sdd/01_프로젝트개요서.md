# 01. 프로젝트 개요서

## 프로젝트명
- 유상사급 타처보관 확인서 생성 프로그램

## 배경
- 분기별로 협력업체에 매출한 자재의 타처보관 현황을 확인하기 위해 사업장별 `자재유형별수불집계` 파일을 취합해 업체별 확인서를 작성하는 업무가 존재한다.
- 현재 업무는 양식 파일과 샘플 산출물을 기준으로 수작업 처리되는 것으로 보이며, 반복 작업과 형식 유지 부담이 크다.

## 목적
- 사업장별 소스 Excel 파일에서 거래처별 대상 자재 목록을 추출해 지정 양식의 재고자산확인서 Excel/PDF를 자동 생성한다.
- Office 미설치 환경에서도 동일한 형식 수준의 산출물을 생성할 수 있도록 한다.

## 범위
- Windows 10/11용 PySide6 데스크톱 프로그램 제공
- 사업장별 소스 파일 다중 입력
- 거래처명 검색 및 다중 선택
- 확인서 미리보기 제공
- 업체별 폴더에 Excel/PDF 생성
- 설치형 배포 파일 제공

## 제외 범위
- ERP 직접 연동
- DB 구축 및 저장
- 사용자 입력 기반 보관 수량 편집 기능
- 생성 이력 로그 관리

## 기대 효과
- 수작업 확인서 작성 시간 단축
- 양식 일관성 확보
- 다중 업체 일괄 생성 지원
- 사업장별 자료 출처 구분 명확화
