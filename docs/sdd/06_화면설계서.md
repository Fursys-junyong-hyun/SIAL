# 06. 화면 설계서

## 화면 1. 메인 화면

### 목적
- 소스 파일 등록, 거래처 선택, 미리보기 확인, 산출 실행을 한 화면 흐름으로 제공한다.

### 입력 항목

| 항목 | 설명 |
|---|---|
| 소스 파일 목록 | 사업장별 `자재유형별수불집계` 파일 등록 |
| 사업장명 입력 | 파일명에서 자동 추출된 값 표시 후 수정 가능 |
| 저장 폴더 | 산출물 저장 기준 폴더 |
| 거래처 검색 | 거래처명 필터링 |
| 거래처 선택 목록 | 체크박스 다중 선택 |

### 버튼
- 파일 추가
- 파일 제거
- 거래처 불러오기
- 미리보기 생성
- 산출 실행
- 저장 폴더 선택

### 상태 표시
- 파일별 읽기 성공/실패 상태
- 선택 거래처 수
- 미리보기 생성 완료 여부
- 산출 진행 상태

### 오류 표시
- 파일 형식 오류
- 필수 컬럼 누락
- 저장 경로 미선택
- 거래처 미선택
- 덮어쓰기 확인 필요

## 화면 2. 미리보기 화면

### 목적
- 업체별 출력 예정 데이터를 생성 전 검토한다.

### 구성
- 선택 업체 탭 또는 목록
- 출력 테이블 미리보기
- 기준일자 표시
- 페이지 분할 예상 정보

### 동작 규칙
- 편집 불가
- 생성 전 검토용으로만 사용
- 누락값은 빈칸 그대로 표시

## UI 스타일 방향
- PySide6 기반
- 블랙 계열
- 모던 스타일
- 명확한 대비와 테이블 가독성 우선

## 미정 또는 사용자 확인 필요
- 미리보기 화면을 메인 화면 내 하단 패널로 둘지 별도 대화상자로 둘지
- 거래처 목록의 전체 선택/전체 해제 UX 상세 방식
