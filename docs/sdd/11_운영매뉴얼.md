# 11. 운영 매뉴얼

## 설치 방법
1. 설치 파일을 실행한다.
2. 설치 경로를 선택한다.
3. 바탕화면 바로가기 생성 여부를 확인하고 설치를 완료한다.

## 실행 방법
1. 프로그램을 실행한다.
2. 사업장별 소스 파일을 등록한다.
3. 자동 추출된 사업장명을 확인하고 필요 시 수정한다.
4. 저장 폴더를 선택한다.
5. 거래처를 검색하고 대상 업체를 다중 선택한다.
6. 미리보기를 생성해 검토한다.
7. 산출 실행으로 Excel/PDF를 생성한다.

## 사용 규칙
- 소스 시트는 `Sheet1`이어야 한다.
- 필수 컬럼은 `거래처명`, `자재코드`, `색상`이며 `자재명`은 없으면 빈칸 처리된다.
- `보관 수량`은 프로그램이 채우지 않는다.
- 동일 파일이 있으면 덮어쓰기 여부를 확인한다.

## 장애 대응
- 파일 읽기 오류 시 파일 손상 여부와 시트명을 먼저 확인한다.
- 필수 컬럼 누락 시 소스 파일 헤더명을 확인한다.
- PDF 생성 실패 시 출력 권한, 경로, PDF 엔진 상태를 확인한다.

## 설정 항목
- 최근 사용 폴더 저장

## 인수인계 체크 포인트
- 양식 파일 위치
- PDF 생성 엔진
- 설치 패키지 생성 방법
- 사업장명 자동 추출 규칙
