# 03. 요구사항 정의서

## 기능 요구사항

| ID | 우선순위 | 요구사항 |
|---|---|---|
| FR-001 | 높음 | 사용자는 사업장별 소스 Excel 파일을 1건 이상 등록할 수 있어야 한다. |
| FR-002 | 높음 | 시스템은 소스 파일명에서 사업장 기본값을 자동 추출해 표시해야 한다. |
| FR-003 | 높음 | 사용자는 자동 추출된 사업장명을 수정할 수 있어야 한다. |
| FR-004 | 높음 | 시스템은 각 소스 파일의 `Sheet1`을 읽어 거래처명 목록을 제공해야 한다. |
| FR-005 | 높음 | 사용자는 거래처명을 검색할 수 있어야 한다. |
| FR-006 | 높음 | 사용자는 체크박스로 여러 거래처를 동시에 선택할 수 있어야 한다. |
| FR-007 | 높음 | 시스템은 선택 거래처에 대해 `자재코드 + 색상`을 키로 목록을 구성해야 한다. |
| FR-008 | 높음 | 동일 키가 중복되면 첫 번째 행만 사용해야 한다. |
| FR-009 | 높음 | 시스템은 출력 데이터를 사업장, 업체명, 자재코드, 색상코드, 비고로 양식에 반영해야 한다. |
| FR-010 | 높음 | 시스템은 `비고`에 소스의 `자재명`을 반영해야 한다. |
| FR-011 | 높음 | 시스템은 `보관 수량`을 공란으로 유지해야 한다. |
| FR-012 | 높음 | 시스템은 여러 사업장 자료를 합산하지 않고 사업장별 별도 행으로 출력해야 한다. |
| FR-013 | 높음 | 시스템은 출력 전 검토용 미리보기를 제공해야 한다. |
| FR-014 | 높음 | 미리보기는 검토 전용이어야 하며 직접 수정은 허용하지 않아야 한다. |
| FR-015 | 높음 | 시스템은 선택 거래처별 폴더를 생성하고 Excel/PDF를 함께 저장해야 한다. |
| FR-016 | 높음 | 산출 파일명은 `거래처명_재고자산확인서_YYMMDD` 형식을 따라야 한다. |
| FR-017 | 높음 | 기준일은 실행일을 사용하고 양식 `B2` 셀에 지정 형식으로 반영해야 한다. |
| FR-018 | 높음 | 시스템은 본문을 4행부터 채우고 페이지 초과 시 자동으로 다음 페이지를 생성해야 한다. |
| FR-019 | 높음 | 페이지가 넘어가면 헤더를 반복하고 꼬리표는 마지막 페이지에만 출력해야 한다. |
| FR-020 | 높음 | 시스템은 동일 파일 존재 시 덮어쓰기 여부를 사용자에게 확인해야 한다. |
| FR-021 | 중간 | 시스템은 최근 사용 폴더를 저장하고 다음 실행 시 재사용할 수 있어야 한다. |
| FR-022 | 중간 | 시스템은 설치형 프로그램으로 배포되어야 하며 바탕화면 바로가기를 생성할 수 있어야 한다. |

## 비기능 요구사항

| ID | 우선순위 | 요구사항 |
|---|---|---|
| NFR-001 | 높음 | 프로그램은 Windows 10/11에서 동작해야 한다. |
| NFR-002 | 높음 | 프로그램은 Office 미설치 환경에서도 Excel/PDF 산출을 지원해야 한다. |
| NFR-003 | 높음 | PDF 결과물은 기준 양식과 거의 동일한 수준의 레이아웃을 유지해야 한다. |
| NFR-004 | 중간 | UI는 PySide6 기반의 블랙 계열 모던 스타일이어야 한다. |
| NFR-005 | 중간 | 컬럼 위치가 달라도 컬럼명 기준으로 데이터를 식별할 수 있어야 한다. |
| NFR-006 | 중간 | 일부 값 누락이 있어도 생성 가능한 문서는 계속 생성해야 한다. |

## 미정 또는 사용자 확인 필요
- PDF 생성 엔진 선택
- 설치 파일 생성 도구 선택
- 파일명에서 사업장 기본값을 추출하는 구체 규칙
