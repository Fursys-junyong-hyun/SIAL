# 07. 시스템 구성도

## 구성 요소

| 구성 요소 | 역할 |
|---|---|
| PySide6 UI | 파일 선택, 사업장명 입력, 거래처 검색/선택, 미리보기, 생성 실행 |
| Excel 읽기 모듈 | 소스 파일 `Sheet1` 읽기, 컬럼명 기반 데이터 식별 |
| 데이터 가공 모듈 | 거래처 필터링, 키 중복 제거, 정렬, 출력 데이터 구성 |
| 양식 렌더링 모듈 | 양식 Excel 파일에 데이터/기준일자 반영, 다중 페이지 구성 |
| PDF 변환 모듈 | Office 미설치 환경에서 PDF 생성 |
| 설정 저장 모듈 | 최근 사용 폴더 저장 및 재사용 |
| 설치 패키지 | 설치 경로 선택, 바로가기 생성 |

## 실행 순서
1. 사용자가 소스 파일과 저장 폴더를 선택한다.
2. UI가 입력값을 수집한다.
3. Excel 읽기 모듈이 데이터 원본을 읽는다.
4. 데이터 가공 모듈이 거래처별 출력 데이터를 생성한다.
5. 양식 렌더링 모듈이 `.xlsx` 산출물을 만든다.
6. PDF 변환 모듈이 `.pdf`를 생성한다.
7. 설정 저장 모듈이 최근 사용 폴더를 기록한다.

## 파일 처리 구조
- 입력
  - 사업장별 `자재유형별수불집계` Excel
  - 양식 Excel
- 출력
  - 거래처별 폴더
  - 거래처별 `.xlsx`
  - 거래처별 `.pdf`

## 미정 또는 사용자 확인 필요
- Excel 읽기/쓰기 라이브러리 조합
- PDF 생성 라이브러리 또는 엔진
- 설치 패키징 도구
